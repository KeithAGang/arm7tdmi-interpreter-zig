# ARM7TDMI Interpreter in Zig

Welcome to the ARM7TDMI Interpreter project! This repository is dedicated to building a full-fledged interpreter for the ARM7TDMI processor core, written entirely in [Zig](https://ziglang.org/).

## Project Goal

The ultimate goal is to create a robust, performant, and accurate emulator for the ARM7TDMI architecture (the core powering devices like the Game Boy Advance). We aim to leverage Zig's modern features, manual memory management, and compile-time capabilities to ensure high efficiency and code clarity.

## Current Status

The project is currently in active development. We are building the core instruction set architecture (ISA) implementation and the simulation loop one step at a time.

For a detailed breakdown of implemented features and current active tasks, please refer to [PROGRESS.md](PROGRESS.md).

## Getting Started

### Prerequisites

*   **Zig Compiler**: Ensure you have the latest version of Zig installed.

### Building and Running

To build and run the current simulation:

```bash
zig build run
```
